# File-Chat 测试文件

这是一个用于测试 file-chat 项目的示例文件。

## 功能列表

1. 文件分片：将长文本按照语义逻辑拆分为多个片段
2. 智能检索：根据用户查询，从片段中选择最相关的内容
3. 上下文扩展：为每个选中片段添加周围的上下文信息
4. 多轮对话：支持追问，增量更新索引

## 技术架构

后端使用 Go 语言实现，调用 DeepSeek v4 Flash 模型。
前端使用 NextChat 项目，通过 OpenAI 兼容 API 接口通信。

## 性能指标

- 分片延迟：< 5秒（2000 token 窗口）
- 检索准确率：> 90%
- 上下文窗口：支持百万级 token 的原始文本
